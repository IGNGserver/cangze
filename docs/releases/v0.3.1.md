A new app icon for Cangze (藏泽), an open-source AI hub for Home Assistant.

> **Prerelease.** The placeholder mark is replaced by the roof-ridge icon. Nothing else in the product changes.

## Highlights

- **App icon**: The Fluent-blue placeholder is gone. The in-app logo and the browser favicon now use the full-bleed roof ridge with the small lamp under the eaves.

## Install or upgrade

```bash
mkdir cangze && cd cangze
VERSION=0.3.1
curl -fsSLO "https://github.com/IGNGserver/cangze/releases/download/v${VERSION}/compose.yaml"
curl -fsSL "https://github.com/IGNGserver/cangze/releases/download/v${VERSION}/env.example" -o .env   # optional
docker compose up -d
docker compose logs cangze | grep -i bootstrap
```

Image: `ghcr.io/igngserver/cangze:0.3.1` (also `:next`), `linux/amd64` and `linux/arm64`.
