Security, reliability and concurrency audit remediation for Cangze (藏泽), an open-source AI hub for Home Assistant.

> **Prerelease.** This release includes comprehensive security, authorization, live data synchronization, and deployment hardening across the entire hub.

## Highlights

- **Agent revision authorization & approvals**: Subagent definitions require immutable revision tracking. Privileged operations and unattended high-risk permissions require explicit administrator authorization; session-directed agent modifications and delegations now require administrator approval.
- **Recursive HA target resolution**: Group entities and domain groups expand recursively before permission evaluation with loop detection, and explicit entity IDs are dispatched to Home Assistant.
- **Live snapshot streams & client reliability**: Sessions, agents, runs, and HA entities use `{ items, streamSeq }` snapshot envelopes. The web UI buffers events during fetch, detects sequence gaps and server restarts, and resynchronizes cleanly.
- **Full-PUT autosave queue**: Settings autosaves serialize sequential mutations so slow responses never overwrite newer user edits, rolling back only the failing edit.
- **Resource boundaries**: Camera streaming caps responses at 25 MiB across chunked streams; history queries enforce a maximum 31-day range; backup decompression is asynchronous with an explicit 1 GiB safety bound.
- **Container and deployment hardening**: Default loopback binding (`127.0.0.1`), read-only container root filesystem, `cap_drop: [ALL]`, `no-new-privileges`, and bounded non-executable `/tmp` tmpfs. Release artifacts produce verifiable provenance and SBOM attestations.
- **Append-only database migrations**: Migration 0006 backfills administrator authorization on revisions; migration 0007 safely removes legacy unused tables.

## Install or upgrade

```bash
mkdir cangze && cd cangze
VERSION=0.4.0
curl -fsSLO "https://github.com/IGNGserver/cangze/releases/download/v${VERSION}/compose.yaml"
curl -fsSL "https://github.com/IGNGserver/cangze/releases/download/v${VERSION}/env.example" -o .env   # optional
docker compose up -d
docker compose logs cangze | grep -i bootstrap
```

Image: `ghcr.io/igngserver/cangze:0.4.0` (also `:next`), `linux/amd64` and `linux/arm64`.
