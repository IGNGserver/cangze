Default port update for Cangze (藏泽), an open-source AI hub for Home Assistant.

> **Prerelease.** This release changes the default HTTP port from `8080` to `38417`.

## Install

```bash
mkdir cangze && cd cangze
curl -fsSLO https://github.com/IGNGserver/cangze/releases/download/v0.1.1/compose.yaml
docker compose up -d
docker compose logs cangze | grep -i bootstrap
```

Open `http://<host>:38417` after startup. To use another host port, set `CANGZE_PORT` in `.env` before
starting the Compose project.

Image: `ghcr.io/igngserver/cangze:0.1.1` (also `:next`), `linux/amd64` and `linux/arm64`.

Existing installations using an explicit `CANGZE_PORT` are unaffected. Installations relying on the old
default must update their URL and published port to `38417`, or set `CANGZE_PORT=8080` explicitly to retain
the old host port.
