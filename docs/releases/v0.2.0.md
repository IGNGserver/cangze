Reliability and resilience update for Cangze (藏泽), an open-source AI hub for Home Assistant.

> **Prerelease.** This release completes the reliability roadmap (stages A through E), bringing
> durable unattended execution, bounded context compaction, usage soft budgets, resilient stream
> recovery, and safe concurrent agent editing.

## Highlights

- **Unattended durability (Stage A & B)**: Durable scheduling with SQLite-persisted jobs, crash recovery for in-flight tasks, and hard boundaries that prevent subagents from creating subagents or modifying permissions.
- **Closed task loop (Stage C)**: Explicit separation between pausing, cancelling queued runs, and stopping in-flight work without rolling back completed Home Assistant writes. Deduplicated, persisted run reports delivered after main sessions.
- **Bounded context & settled budgets (Stage D)**: Automatic context compaction at token thresholds with continuous reconstruction from persisted history. Soft usage budgets computed from settled runs; unknown pricing strictly blocks budgeted tasks while explicit zero pricing remains free.
- **Agent editing & stream recovery (Stage E)**: Three-way JSON merge preserving remote additions with explicit conflict selection for diverging fields; atomic permission and trigger lists. Controlled trigger JSON with validation guards against saving and firing invalid triggers. Epoch-safe WebSocket reconnection and REST snapshot reconciliation above the sequence floor. Mobile notification navigation to run transcripts and stable `(queued_at, id)` run-history pagination.

## Install or upgrade

```bash
mkdir cangze && cd cangze
VERSION=0.2.0
curl -fsSLO "https://github.com/IGNGserver/cangze/releases/download/v${VERSION}/compose.yaml"
curl -fsSL "https://github.com/IGNGserver/cangze/releases/download/v${VERSION}/.env.example" -o .env   # optional
docker compose up -d
docker compose logs cangze | grep -i bootstrap
```

Image: `ghcr.io/igngserver/cangze:0.2.0` (also `:next`), `linux/amd64` and `linux/arm64`.
