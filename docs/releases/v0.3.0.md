Composer drafts and a safer first message for Cangze (藏泽), an open-source AI hub for Home Assistant.

> **Prerelease.** New chats stay unsent until you send the first message, and drafts follow you across
> devices with text and images.

## Highlights

- **New chats are drafts, not empty sessions**: Clicking _New session_ opens one shared, unsent draft; no
  conversation row exists until the first message. Sending that message creates the session, persists the
  user entry and consumes the draft in a single transaction, so an abandoned click no longer leaves an
  empty conversation behind.
- **Drafts sync across devices**: Each session keeps its unsent text and up to four image attachments
  server-side. Autosave is revision-checked, so another device can continue the same draft, and concurrent
  edits surface an explicit _load latest / keep mine_ choice instead of silently overwriting each other.
- **Images in drafts**: Attachments are stored with the draft and become part of the user message when it
  is sent; they survive reloads and device switches. Bytes are fetched from an authenticated endpoint and
  never travel over the stream.
- **Home Assistant grouping fix**: Configuration and service entities no longer appear in room grouping.

## Install or upgrade

```bash
mkdir cangze && cd cangze
VERSION=0.3.0
curl -fsSLO "https://github.com/IGNGserver/cangze/releases/download/v${VERSION}/compose.yaml"
curl -fsSL "https://github.com/IGNGserver/cangze/releases/download/v${VERSION}/.env.example" -o .env   # optional
docker compose up -d
docker compose logs cangze | grep -i bootstrap
```

Image: `ghcr.io/igngserver/cangze:0.3.0` (also `:next`), `linux/amd64` and `linux/arm64`.
