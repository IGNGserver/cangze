Fluent 2 visual system refinement for Cangze (藏泽), an open-source AI hub for Home Assistant.

> **Prerelease.** This release unifies the web UI's layout, spacing, radius, surface, typography and responsive component language across sessions, agents, devices, settings, logs, authentication and the welcome flow.

## Highlights

- **Unified Fluent 2 design tokens**: shared spacing, width, radius, shadow, surface and control tokens replace scattered page-level measurements.
- **Cohesive shell and page frames**: navigation rail, split panes, headers, cards and settings sections now share consistent hierarchy and alignment.
- **Refined conversation experience**: centered message column, stable composer geometry, improved markdown/code rhythm, user message treatment and prompt spacing.
- **Consistent device and agent surfaces**: tiles, lists, tables, forms, tabs, drawers and detail panels use the same border, radius and spacing language.
- **Responsive and theme-aware**: light and dark themes are aligned across desktop and mobile layouts, with updated reference screenshots.
- **Navigation stability**: browser-router transitions are configured for deterministic state updates during rapid session creation and draft interactions.

## Install or upgrade

```bash
mkdir cangze && cd cangze
VERSION=0.4.1
curl -fsSLO "https://github.com/IGNGserver/cangze/releases/download/v${VERSION}/compose.yaml"
curl -fsSL "https://github.com/IGNGserver/cangze/releases/download/v${VERSION}/env.example" -o .env
docker compose up -d
docker compose logs cangze | grep -i bootstrap
```

Image: `ghcr.io/igngserver/cangze:0.4.1` (also `:next`), `linux/amd64` and `linux/arm64`.
