Test-platform authentication update for Cangze (藏泽), an open-source AI hub for Home Assistant.

> **Prerelease.** This release allows six-character administrator keys so the test platform can use the
> requested `100728` credential.

## Install

```bash
mkdir cangze && cd cangze
curl -fsSLO https://github.com/IGNGserver/cangze/releases/download/v0.1.2/compose.yaml
docker compose up -d
docker compose logs cangze | grep -i bootstrap
```

Open `http://<host>:38417` after startup. The administrator key may contain six or more characters; use a
long, unique key for any deployment exposed beyond a trusted test network.

Image: `ghcr.io/igngserver/cangze:0.1.2` (also `:next`), `linux/amd64` and `linux/arm64`.
