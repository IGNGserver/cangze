# 藏泽 · Cangze

> 夫藏舟于壑，藏山于泽，谓之固矣。 ——《庄子·大宗师》

**藏泽（Cangze）** 是一套开箱即用的私有部署智能家居控制中枢，使用 Docker Compose 快速构建与运行。

## 核心特性

- **网页控制台**：现代化 Web 交互界面，实时查看与控制家庭设备及会话；
- **大模型驱动**：配置 API 密钥连接大语言模型（LLM），支持复杂意图理解与自然语言对话；
- **Home Assistant 深度集成**：大模型调度 Home Assistant 开放接口，安全、精确地完成家电与传感器自动化操作；
- **容器化私有部署**：完整中枢通过 Docker Compose 部署运行，数据全私有、无强制遥测。

## 快速开始

```bash
docker compose up -d
```
